# dsh-session-tidy

DSH 侧栏任务命名助手：把任务名统一成 `MMDD｜类型｜主题`，并提供一个批量整理、归档、置顶的面板。

## 命名规范

- 格式：`MMDD｜类型｜主题`，例如 `1026｜功能｜侧栏任务名整理`。
- 日期取会话的 `createdAt`，按 `Asia/Shanghai` 换算成 `MMDD`；**不使用 `updatedAt`**。取不到 `createdAt` 时用当前时间。
- 类型只能取：功能、设计、修复、优化、发布、探索、文档、研究。
- 主题 2–12 个汉字，概括实际任务对象与动作；不重复项目名，不加标点、引号、表情、编号。
- 判断不出主题时保留原名，不猜测。

## 自动命名

- 启动时如果当前会话还没按规范命名，自动命名一次；新任务在首条提问落地后同样自动命名一次，不需要确认。
- 只作用于当前会话，不扫描、不改动其他会话；不改项目名、项目归属、排序、置顶、归档。
- 已经符合 `MMDD｜类型｜主题` 的标题不会再被自动改名；本地账本保证同一任务最多自动命名一次。
- 面板里可以关闭「自动命名新任务」，关掉后只保留手动整理。

## 整理面板

- 侧栏「任务批量命名助手」页按工作区分组列出会话，未按规范命名的都算待整理。
- 「AI 重命名」把会话开头几句原话交给默认模型，返回合规标题，先预览再应用。
- 支持选中本页、应用、撤销上次整理、批量归档、批量置顶；行菜单「⋯ → 整理标题…」可单条改。
- 规范名显示「规范」标签，并自动从「待整理」里排除。

## 限制

标题是会话持久状态：**改名即钉住**，之后对话中的自动标题不再覆盖。撤销是写回旧标题，不能退回「尚未命名」状态。

## 安装

从插件页「发现」安装，或手动：

```bash
pnpm add dsh-session-tidy
```

并把它放进 profile 的 `dsh.profile.bundles`：

```yaml
dsh:
  profile:
    bundles:
      - "@deepseek-ai/dsh-base"
      - "@deepseek-ai/dsh-web-app"
      - "dsh-session-tidy"
```

Host 半边注册两个同源路由：

- `GET  /plugin/session-tidy/v2/info` — 模型路由、类型表与格式
- `POST /plugin/session-tidy/v2/suggest` — 批量命名（最多 12 条）

## 文件

| 文件 | 作用 |
|---|---|
| `index.js` | Host 半边：读 `createdAt`、项目名、开头几句，调用 `ctx.llm`，拼装并校验标题 |
| `client.js` | 浏览器半边：面板、行菜单、对话框、自动命名监听 |
| `cordis.patch.yml` | bundle 补丁，插入 `session-tidy` 行 |
| `locale/*.json` | 插件页展示用的标题与描述 |
| `icon.svg` | 插件页图标 |
