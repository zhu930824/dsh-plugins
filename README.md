# DSH plugins

DSH plugin market index and the plugins it lists.

- `dsh-session-tidy/` — 任务批量命名助手：把 DSH 任务名统一成 `MMDD｜类型｜主题`，并支持批量整理、归档、置顶。
- `market-index.json` — format-1 market index for this repository.

## 在 DSH 里添加

1. 启用「插件市场」组合包（插件 → 更多 → 实验性插件）。
2. 插件 → 发现 → 添加索引源，填入本仓库 `market-index.json` 的 raw 地址。
